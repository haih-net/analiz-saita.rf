# Анализ сайта — структура

Основа соглашений — последний коммит сайта ии-поддержка-сайта.рф `aa4956c6a74c` (Redesign). Содержание относится к анализу сайта; цены и обязательства сопровождения не переносятся.

- `pages/HomePage/index.tsx` экспортирует `HomePage: React.FC`; главная владеет своей композицией и `styles.ts`.
- Остальные страницы — `TrafficPage`, `EnquiriesPage`, `SpeedPage`, `UsabilityPage`, `TechnicalPage`, `ContentPage`, `HowItWorksPage`, `ExperiencePage`, `ContactPage`. Каждая экспортирует свой именованный компонент из собственного `index.tsx`.
- `components/LandingPage` предоставляет композиционные параметры `visual` и `children`, `DetailSection` и общий `AnalysisSummary`. Страница определяет содержание и визуал, без обязательной универсальной схемы данных.
- `components/SiteLayout` владеет оболочкой, sticky-шапкой, навигацией, фокусом, подвалом и стилями документа/ошибок. `AgentConversation` отвечает за честный статус будущего чата. На контактах он размещён в самой странице, без дублирования.
- `app/routes/*.tsx` — только импорт страничного компонента, handle/meta и экспорт на границе React Router. В `app/routes.ts` остаётся исходный `flatRoutes()`. Новые страницы обнаруживаются по именам файлов.
- Локальные ресурсы лежат рядом со страницей: портрет в `ExperiencePage/assets`. Общие компоненты не импортируют страницы и их ресурсы.

Перед наполнением клона удалить посторонние страницы из файлового роутинга, sitemap и предрендеринга. По поручению владельца от 7 октября блог и Solutions отключены: маршрутные модули удалены, их URL возвращают 404. Исходный flatRoutes() сохраняется. При изменении маршрутов согласованно обновлять sitemap, предрендеринг и проверки; очищать старую сборку.

Локально: `PORT=3102 HMR_PORT=24680 npm run dev`. Проверки: `npm run types`, `npm run build`, `npm run test:seo`. Production-просмотр: `PORT=3103 npm start`. История архитектурной ошибки и исправления: Wiki `/wiki/tasks/site-analysis`. Публикация и ИИ-чат не выполнены.
